## Abrir en Visual Studio Code

1. Abre la carpeta `axis-core-redesign`.
2. Abre `index.html`.
3. Recomendado: usa la extensión **Live Server**.
4. Para publicar, sube la carpeta completa manteniendo `assets/` junto a los archivos HTML/CSS/JS.
